# Bundled ambience prototypes

These files are original procedural sound textures generated for this starter (noise beds, modulated ambience, and synthetic chirps). They are not commercial-quality field recordings. They can be used to test mixer behavior while the app is offline. For a production release, replace them with licensed sound recordings and retain license records.


- `rain.wav` — rain-like broadband texture
- `ocean.wav` — modulated wave-like noise
- `forest.wav` — forest-like bed with synthetic chirps
- `fireplace.wav` — crackle texture with synthesized pops
- `wind.wav` — wind/gust noise
- `birds.wav` — synthetic chirp sequence over a soft bed
- `white_noise.wav` — white noise
- `brown_noise.wav` — brown-noise-like low rumble
- `pink_noise.wav` — pink-noise-like texture
- `cafe.wav` — soft cafe-like noise and synthetic tonal events
